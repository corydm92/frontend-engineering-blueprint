# 6 Type Inference and Satisfies — Summary 🧭

This directory shows how to keep **runtime schemas** and **TypeScript types**
aligned. You’ll learn how to infer types from schemas, how to distinguish input vs
output types, and how to enforce alignment with `satisfies`.

## Outcomes

- Generate types from schemas reliably.
- Understand when input/output types differ.
- Enforce schema‑type alignment without guesswork.
