# z.infer, Input, and Output Types 🧠

## Goal

Understand how schema types are derived.

## What you learn

- `z.infer` gives you the **output** type of a schema.
- `z.input` and `z.output` distinguish raw input vs parsed output.

## Explanation

Zod can **transform** data, which means the input type may differ from the output
type. For example, `z.coerce.number()` accepts strings but outputs numbers. Use
`z.input` when you care about what the schema accepts, and `z.output` when you care
about what your code receives after parsing.

## Example

Frontend example — File: `@app/src/schemas/pagination.ts`

```ts
import { z } from 'zod';

const PageSchema = z.object({
  page: z.coerce.number().int().min(1),
});

export type PageInput = z.input<typeof PageSchema>;
export type PageOutput = z.output<typeof PageSchema>;
```

## Pitfalls

- Assuming `z.infer` always reflects raw input.
- Skipping output types when transforms are present.
