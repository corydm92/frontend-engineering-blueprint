# Arrays, Enums, and Unions — Summary

This directory covers collection and variant modeling: arrays, tuples, enums, and
unions. These patterns are essential for API responses, UI lists, and variant
payloads.

You’ll learn the difference between `z.union` and `z.discriminatedUnion`, and when
to use tuples vs arrays for fixed‑length data.

## Outcomes

- Model lists and fixed tuples reliably.
- Represent finite sets with enums and literals.
- Encode success/error or variant response types.
