# 5 Refinements and Effects — Summary 🧭

This directory covers **custom validation** and **transformations**. Refinements
let you enforce rules that aren’t expressible in the base schema, while transforms
let you normalize data into the shape your app expects.

You’ll learn when to use `refine` vs `superRefine`, and when to preprocess input
before validation.

## Outcomes

- Add custom business rules with clear error messages.
- Normalize or transform input without manual parsing.
- Keep validation logic co‑located with schemas.
