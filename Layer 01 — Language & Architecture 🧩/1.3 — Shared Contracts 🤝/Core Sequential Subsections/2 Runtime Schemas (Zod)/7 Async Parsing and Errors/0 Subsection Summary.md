# 7 Async Parsing and Errors — Summary 🧭

This directory covers **async validation** and error mapping. Async parsing is
required when validation depends on I/O (database checks, remote APIs).

You’ll learn how to use `parseAsync` / `safeParseAsync` and how to map error issues
into the shapes your API or UI expects.

## Outcomes

- Validate with async rules safely.
- Choose the correct parsing API for async checks.
- Standardize error mapping for downstream consumers.
