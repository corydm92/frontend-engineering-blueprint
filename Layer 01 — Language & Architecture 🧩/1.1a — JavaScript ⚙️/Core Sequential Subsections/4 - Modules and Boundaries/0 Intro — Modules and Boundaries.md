# Modules and Boundaries — Summary

Modules are the unit of dependency in JavaScript. Good module boundaries make codebases
navigable; bad boundaries create cycles, hidden coupling, and refactor fear.

This directory focuses on ESM basics, dependency hygiene, and patterns that keep imports
predictable as the codebase grows.

## Outcomes

- Use ESM exports intentionally.
- Prevent circular dependencies.
- Keep shared modules from becoming dumping grounds.
- Refactor without widening the dependency graph.
