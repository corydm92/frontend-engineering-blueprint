# 1.1a — JavaScript ⚙️

JavaScript is the runtime reality of frontend systems. This section teaches the language
from first principles through advanced usage, with a focus on predictable behavior under
real concurrency and platform constraints.

## Covers

- Language foundations: scope, closures, hoisting, `this`, objects, prototypes
- Runtime model: call stack, tasks, microtasks, rendering timing
- Async patterns: promises, `async`/`await`, cancellation, error propagation
- Module boundaries: ESM, circular deps, lazy loading, dependency hygiene

## How to use

1. Read `Base Project Rules and Tooling/README.md` for non-negotiables.
2. Follow `Base Project Rules and Tooling/__Initialization/` to set a runtime baseline.
3. Work through `Core Sequential Subsections/` in order, completing each tutorial.
4. Use `Supporting Atomic Notes/` for quick reference and gotchas.
