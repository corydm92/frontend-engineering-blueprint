# TypeScript Foundations — Summary

TypeScript is a compile-time system layered on top of JavaScript. It does not change runtime
behavior; it narrows what you _can_ express in code so invalid states are rejected early.

This directory builds the mental model: erasure, structural typing, type/value namespaces,
module boundaries, and environment types.

## Outcomes

- Explain why types disappear at runtime.
- Use structural typing intentionally.
- Avoid confusion between type and value namespaces.
- Configure environment types correctly.
