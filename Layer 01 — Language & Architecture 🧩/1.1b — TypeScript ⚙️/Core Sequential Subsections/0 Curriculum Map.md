# TypeScript Curriculum Map

This map is ordered from beginner → advanced. Each topic is covered in the listed order.

## Topics

- Types exist only at compile time (erasure)
- Structural typing and assignability
- Type vs value namespaces
- Type-only imports and module boundaries
- Environment types and lib targets (DOM vs Node)
- Type aliases vs interfaces
- Generics and constraints
- Utility types and type transforms
- Control flow narrowing
- Discriminated unions
- Type guards and exhaustiveness
- Typing async boundaries (`Promise<T>`, `Result<T, E>`)
- Modeling error states with unions

- None
