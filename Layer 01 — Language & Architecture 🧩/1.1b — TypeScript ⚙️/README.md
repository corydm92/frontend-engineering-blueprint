# 1.1b — TypeScript ⚙️

TypeScript is how we make JavaScript codebases predictable at scale. It adds a static
analysis layer that catches invalid states early and makes refactors safe.

## Covers

- Type system fundamentals and structural typing
- Type modeling patterns (aliases, interfaces, generics, utility types)
- Narrowing, type guards, and exhaustiveness
- Typing async flows and error states

## How to use

1. Read `Base Project Rules and Tooling/README.md` for non-negotiables.
2. Follow `Base Project Rules and Tooling/__Initialization/` to set a strict baseline.
3. Work through `Core Sequential Subsections/` in order, completing each tutorial.
4. Use `Supporting Atomic Notes/` for quick reference and gotchas.
